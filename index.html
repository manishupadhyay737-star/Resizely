Frequently Asked Questions

Common questions about Resizely.

Is Resizely free?

Yes. The image resizing and compression tool is free to use and does not require an account.

Are images uploaded?

No. Image processing happens in your browser, so the core tool does not need to upload image pixels to a server.

Which formats are supported?

JPG, PNG, WebP and GIF files can be selected. JPG, PNG and WebP are available as output formats.

Can I resize multiple images?

Yes. Multiple images can be added and processed in the same session.
